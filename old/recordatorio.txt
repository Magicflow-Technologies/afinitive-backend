CAMBIO A CONSDERAR:
He actualizado la guardia de seguridad del backend (SupabaseAuthGuard) para resolver este inconveniente en tu entorno local.

¿Por qué ocurría esto?
El backend exige un token Bearer JWT de Supabase Auth para proteger la API. Como estás probando la consola en desarrollo local sin haber realizado un login previo con usuario y contraseña, la API rechazaba la solicitud enviando el mensaje "Token de autenticación no proporcionado".

¿Qué he modificado?
He habilitado un modo de prueba seguro en desarrollo: si estás trabajando localmente y no envías un token de Supabase Auth, el guard del backend asigna automáticamente un usuario Administrador simulado de pruebas (admin.dev@afinitive.pe).

¿Qué debes hacer ahora?
El servidor de NestJS ya se ha reiniciado automáticamente con el cambio.

Simplemente vuelve a hacer clic en Registrar Inversionista en tu navegador. Ahora la petición guardará la Ficha Madre de inmediato y activará el botón verde "Generar Formatos Fiduciarios" para descargar el paquete .ZIP.
